## Atualizar

Todo o conteúdo editável fica nas listas no fim do `index.html`:
`TICKER`, `SCARS`, `PROJECTS`, `SKILLS`, `NOW` e `CERTS`.
Imagens ficam em `assets/`.

Depois de editar:

```powershell
git add -A
git commit -m "Atualiza portfólio"
git push
```

O GitHub Pages republica sozinho em cerca de um minuto.
